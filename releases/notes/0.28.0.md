## New
- Adds local usage highlights for the latest three sessions today and the highest-token session in the current week

## Improvements
- Tails Claude-family transcripts incrementally to reduce repeated parsing and memory pressure as large files grow
- Completes English and Simplified Chinese translations for Settings options, mascot names, loading states, and release notes, with catalog and model-copy coverage

## Fixes
- Prevents startup crashes when recovered Codex history contains repeated or empty `call_id` values
- Fixes the standalone Settings window not receiving the app-selected locale, which left loading titles, mascot names, and sub-agent options tied to the system language
