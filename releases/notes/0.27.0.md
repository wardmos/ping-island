## New
- Adds local and remote SSH session support for Antigravity CLI while preserving Antigravity's native permission flow
- Adds hookless live-state recovery for Codex sessions running in VS Code

## Fixes
- Fixes Qoder CLI question answers submitted in Ping Island falling back to a second terminal confirmation
- Fixes managed hooks not being installed for current Kimi Code releases using `.kimi-code/config.toml`
- Fixes Claude Desktop hook writes being reported as delivered before the app acknowledges processing them
- Fixes real Codex sessions being hidden or replaced by empty Claude placeholder sessions in the same workspace

## Notes
- The Sparkle build number is now `68`, and the app version is now `0.27.0`
- This release is based on latest `main` and is published as GitHub latest
